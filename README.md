# finassist

It is InProgress project for learning AI implementation







To run on Windows:

* Install python on PowerShell "winget install Python.Python.3.12"
* verify "pyhton3 --version"
* Create a virtual environment in project "python3 -m venv .venv"
* then activate it ".venv\\Scripts\\activate"
* then run "pip install -r requirements.txt". This is Python's packages.config
* To run the project root: `uvicorn app.main:app --reload`
* API models: download Ollama from "ollama.com"
